# Glossary

| Term | Meaning |
| --- | --- |
| Armory | The program that registers templates, mints items, runs votes and equips |
| Bounty | SOL paid from a war chest for raid points, or to whoever runs a crank step |
| Composite | One item running up to four modules in one slot |
| Counter-strike | A war chest buying back and burning its own token after a sharp drop |
| Crank | A permissionless instruction anyone can send, paid a capped bounty |
| Cut | The part of a transfer or swap an item takes, within its slot's bound |
| Epoch byte | The first byte of a slot's memory range; changes on every equip so old data reads as empty |
| Equip vault | Where a slot's token-side cuts wait for settlement |
| Forge | Burn two items of one template to mint one stronger item |
| Graduation | When a launch curve fills: the pool tops up, liquidity locks for good |
| Holder memory | 64 bytes per holding, split into one range per slot |
| Item | A template plus parameters, owned as a supply-1 token |
| Kit | The launch rules: holder rewards, max wallet, creator and early-buyer locks |
| Loot | Items minted from a season's loot table when raid tickets are rolled |
| Manifest | The most an item may do: cut, refuse, burn, memory bytes |
| Notice | Delay between a passed vote and the new item taking effect |
| Passport | An agent's on-chain identity |
| Pool-cuts vault | Where all pool items' cuts on a token wait for settlement, in SOL |
| Raid | A buy of one token paid for by selling another, recognized from the route |
| Raid points | Per-holder counters from raids; claimable as bounty or spent on loot |
| Raze | Selling captured territory, rate-limited |
| Royalty | An item owner's share of what the item collects |
| Season | A competition window with an on-chain winner |
| Settle | The permissionless step that pays royalties and item destinations from vaults |
| Siege | A war chest spot-buying a rival after enough raid volume from it |
| Slot | A position in a token's slot table that holds one item |
| Template | Audited hook code with parameter floors, ceilings and forge rules |
| Treaty | A two-sided item that pays each token's holders from the other's trades |
| TWAP | Time-weighted average price, read from the price ring in each pool |
| War chest | A token's code-controlled vault for sieges, counter-strikes and bounties |
| War orders | The War-kind item that configures a token's chest |
