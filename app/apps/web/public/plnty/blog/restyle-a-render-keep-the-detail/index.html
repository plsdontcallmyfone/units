Restyle a render. Keep the detail.

Before you begin

Guide fact sheet

Tools: Styler

You start with: a render you want to develop and a few style references

You end with: a chosen direction with close-ups, an upscale and motion

Have a render or image you want to develop, plus a few style references. This lesson begins with a Cinema 4D / Redshift landscape, but the core exercise is about working from your own image.

You’ll explore how references change its visual language, compare which details survive, and develop a direction for close-ups and motion.

01 / Load

Load your render and references

Place the source render and reference images on the board. Give each reference a clear role: one might establish color, another texture or atmosphere.

02 / Set up

Set up the style transfer

In Plnty

Styler, the subject and style canvases

The lesson demonstrates style transfer and object mixer nodes, with references called into the prompt.

Use the subject and style canvases in Styler. The lesson demonstrates style transfer and object mixer nodes, with references called into the prompt. Keep the first test simple so you can see what each reference changes.

03 / Compare

Compare the directions

Run the transfers and look at the details you need to retain. In this example, branch shapes and fine tree detail are the test of whether a direction is useful.

Pause after each transfer and compare it with your original render. An attractive result is only useful if it preserves what matters to the project.

04 / Develop

Develop the selected frame

Explore close-ups, upscale the image, and try a short motion treatment. Review each step against the direction you chose.

What should I prepare before starting?

Bring a render or image you want to develop and a small set of style references. Decide which shapes, details, and compositional choices should remain consistent.
