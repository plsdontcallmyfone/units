Plnty documentation

How to work in Plnty: the canvas, the tools, and team spaces.

Plnty is a collaborative workspace for concept development and design. Image, video, 3D, vector and sound live together on one infinite canvas, and these pages cover how to work in it.

Each entry names the question its page answers. Start at the top if Plnty is new to you.
